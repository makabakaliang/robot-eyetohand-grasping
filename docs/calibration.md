# Eye-to-Hand 手眼标定说明

该版本采用 eye-to-hand 视觉布局：RealSense 相机固定在机械臂外部，目标是在机械臂基坐标系和相机坐标系之间求出固定外参 `T_base_cam`。

## 标定输入

标定时分别采集两类数据：

- `apriltag_poses_original.txt`：AprilTag / ArUco 标定板在相机坐标系下的位姿。
- `robot_base_poses_original.txt`：对应采样时机械臂基坐标系下的位姿。

采集流程：

1. 将 AprilTag 标定板放在机械臂可达工作区内。
2. 机械臂移动到多个观测位姿。
3. 相机检测 AprilTag，记录标定板在相机坐标系下的位置和姿态。
4. 同步记录机械臂基坐标系下的目标或末端位姿。
5. 使用 `hand_eye_calibration.py` 计算相机到机械臂基座的变换矩阵。

## 标定输出

当前仓库保留的结果文件：

- `T_base_cam.txt`
- `T_base_cam.npy` 未上传，属于本地二进制运行结果。

## 在抓取流程中的作用

视觉模块先通过 YOLO 和 RealSense 深度图得到硬盘在相机坐标系下的位置，再用 `T_base_cam` 将目标转换到机械臂基坐标系。之后系统会继续应用 TCP 工具补偿和人工微调补偿，生成最终抓取位姿。

## 工程备注

eye-to-hand 方案的优势是视野稳定、适合固定工位和多目标搜索；不足是相机容易受到工位遮挡影响，且标定精度会直接影响最终抓取误差。该版本保留了标定数据和结果，便于展示从视觉测量到机械臂坐标转换的完整链路。
